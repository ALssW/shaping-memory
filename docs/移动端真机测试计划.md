## 一、前置准备

### 1.1 工具链

| 项 | 要求 |
| --- | --- |
| JDK | 17（RN 0.76 要求） |
| Android SDK | 含 `platform-tools`（`adb`）、`build-tools`、`platforms;android-35` |
| 设备 | Android 真机（建议 API 30 及以上），已开启开发者选项与 USB 调试 |
| iOS（可选） | macOS + Xcode 15+；真机需配置开发者证书 |

本次调试目标的 ABI 由 `plugins/withAndroidPatches.js` 固定为 `arm64-v8a`。若设备为 32 位 `armeabi-v7a`，需先改为 `arm64-v8a,armeabi-v7a` 再构建；若目标是 x86_64 模拟器，需改为 `x86_64`。

### 1.2 构建与安装

PowerShell 环境执行策略禁用了 `.ps1`，必须使用 `npx.cmd` / `npm.cmd`。

```powershell
# 1) 生成原生工程（含本项目的 7 处 Android 补丁）
npx.cmd expo prebuild --platform android --clean

# 2) 打包期注入 API 域名：真机上的 127.0.0.1 指向手机自身，必须显式指定
$env:EXPO_PUBLIC_API_BASE = "https://<YOUR_DOMAIN>/shaping-memory/api"

# 3) 编译并安装到已连接的真机
npm.cmd run android

# 或直接出 release 包（release 签名凭据放 apps/mobile/credentials/，缺失时退化为 debug 签名）
cd apps/mobile/android; ./gradlew assembleRelease
```

> `expo-video` 必须经过 `prebuild` 并重打包后才会进入原生工程；直接使用 Expo Go 时，其内置的 `expo-video` 版本与项目声明的 `~2.0.6` 可能不一致，实况播放功能不得在 Expo Go 上判定。

### 1.3 服务端与网络

| 项 | 要求 |
| --- | --- |
| API | 可被设备访问；开发期若用局域网地址，`android:usesCleartextTraffic="true"` 已由补丁开启，可直接走 http |
| 地图瓦片 | 高德瓦片（`https://webrd0{s}.is.autonavi.com/...`）需联网 |
| 测试数据 | 至少包含：普通照片、含 EXIF 照片、含 GPS 照片、实况照片（`isLive` + `liveUrl`）、隐私照片（`mode=blur`、`mode=hidden`）、独立密码照片、多分类、多相册 |

### 1.4 日志与证据抓取

```powershell
adb logcat -c                      # 清缓冲
adb logcat *:E ReactNativeJS:V     # 只看错误与 JS 日志
adb shell dumpsys meminfo <包名>    # 内存
adb shell dumpsys gfxinfo <包名>    # 帧率（需先操作一段时间）
adb exec-out screencap -p > shot.png
```

包名：`cn.alsw.shapingmemory`
